Before the course: prepare your laptop

2300506 Industrial Science · Huaqiao University · Block 1: 23 and 24 January 2027 · Block 2: 27 and 28 March 2027

Every session has a workshop on your own laptop. Please set it up at least one week before Block 1, so that no class time is lost on installation. It takes about 30 minutes.

2 · Spreadsheet and Solver

Microsoft Excel

  • Windows: File › Options › Add-ins › Manage: Excel Add-ins › Go › tick Solver Add-in › OK. Solver then appears on the Data tab.
  • macOS: Tools › Excel Add-ins › tick Solver Add-in › OK.

WPS Office

Open a spreadsheet and look for Solver on the Data tab. If your version has no Solver, you can still do every Block 1 workshop: only one step of W4 uses Solver, and the workshop explains a manual alternative. For Block 2 you will need Solver or Python.

Test: open any workbook and check that Solver opens. Close it again.

3 · Python

  1. Install Python 3.11 or newer. Download it from python.org. On Windows, tick "Add python.exe to PATH" on the first screen of the installer. If you already use Anaconda, you can keep it and use the Anaconda Prompt for the next step.
  2. Install the packages. Open a terminal (Windows: Command Prompt or Anaconda Prompt; macOS: Terminal) and paste this one line. It uses the Tsinghua University mirror, which is fast in mainland China: 
    python -m pip install -i https://pypi.tuna.tsinghua.edu.cn/simple numpy scipy pandas matplotlib jupyterlab "pulp>=3,<4" highspy
    On macOS, if python is not found, type python3 instead of python in this and the next step.
  3. Check your setup. Download check_setup.py from the course page (soorathep.github.io/course-2300506), then in the terminal go to the folder where you saved it and run: 
    python check_setup.py
    Every line should start with [OK] and the last line should say READY. A line starting with [FIX] tells you the command to run; run it, then check again.
The course uses PuLP 3. PuLP 4 changed how models are written, so the course notebooks will not run with it. The install line above already chooses PuLP 3.

4 · Course files

  • Slides, workshop files and reading notes are on the course page and on the instructor's drive in class. If the course page loads slowly, copy the files from the drive on the first day.
  • To open a slide deck offline: unzip the offline copy and double-click the session file, for example s01.html. Narration and captions work offline.
  • Workshop files: enter your student ID, name and group number on the Start sheet. Your group number is given in the first class.

5 · If something does not work

Run python check_setup.py again and keep its output. Bring your laptop and the output to the first class; we will fix the remaining problems in the first break.
