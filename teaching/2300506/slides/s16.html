Question for today: a worn die lip makes the coating drift slowly heavier. Which chart notices first?

Rational subgroups

Each hour, five coupons are punched across the web at the same moment: one subgroup.

Variation within a subgroup is short-term, common-cause noise. Variation between subgroups adds anything that changes over time.

Control limits are built from within-subgroup variation, so a shift between hours stands out.

A poor choice: five coupons taken over five hours as one subgroup. Hour-to-hour drift then inflates the ranges, widens the limits and hides the drift it should reveal.

Read the R chart first. If within-subgroup spread is not stable, the X-bar limits, which use R̄, mean nothing.

Control limits are not specification limits. Limits describe what the process does (19.82 to 20.28 for subgroup means); the specification describes what the customer needs (19.4 to 20.6 for single coupons).

Constants for subgroups of 5: A2 = 0.577, D3 = 0, D4 = 2.114, d2 = 2.326.

Individuals data and run rules

I-MR chart. When one reading arrives at a time (one viscosity test per slurry batch), chart the individual values, with σ estimated from the average moving range: σ = MR̄ / 1.128.

Western Electric run rules. Signal if:

  1. One point beyond 3σ.
  2. Two of three successive points beyond 2σ on the same side.
  3. Four of five beyond 1σ on the same side.
  4. Eight in a row on one side of the center line.

Each rule added catches smaller shifts sooner, but also raises false alarms. With all four rules, an in-control process gives a false alarm about every 92 subgroups instead of every 370.

All three charts raise a false alarm about once every 370 subgroups. For a shift of half a standard error, 0.04 mg/cm², the X-bar chart needs about 155 hours, almost a week of production, to notice; EWMA needs about 25.

Run lengths from simulation, as checked for this course. σx̄ = 0.172 / √5 = 0.077 mg/cm².

Charts with memory

EWMA (exponentially weighted moving average)

zt = λ x̄t + (1 − λ) zt−1, starting at z0 = 20.05

With λ = 0.1, each new subgroup gets 10% weight and older subgroups fade. Limits narrow to 20.05 ± 0.048 mg/cm².

CUSUM (cumulative sum)

Ct = max(0, Ct−1 + (x̄t − 20.05)/σx̄ − k)

Small deviations in one direction accumulate; the sum signals when it exceeds h. A matching lower CUSUM catches drifts downward.

Both charts trade a slower response to one large jump for a much faster response to small sustained shifts. Many lines run a Shewhart chart and an EWMA side by side.

Drift detectives

Activity · Drift detectives

Groups of 4 · 25 minutes · detection time for each chart

Subgroup means are revealed one hour at a time. Update both charts on paper. Raise the red card at your first signal on either chart.

  1. Before you start: compute the X-bar limits and the EWMA limits for the first three subgroups.
  2. Plot each new mean on the X-bar chart and update zt on the EWMA chart.

What we learned

Rational subgroups put short-term noise inside the subgroup, so changes over time show between subgroups.

Read the R chart before the X-bar chart. Control limits describe the process; specifications describe the customer’s need.

For small sustained drifts, EWMA and CUSUM signal several times faster than an X-bar chart at the same false-alarm rate.
