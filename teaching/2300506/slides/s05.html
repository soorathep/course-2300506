Question for today: what share of the cells CellCo starts ends up good, and which improvement buys the most yield per yuan?

The cell’s journey

Every cell passes Formation (F) and the Aging test (A). A cell that fails goes to Rework (R) and is tested again. It ends either Good (G) or Scrap (S).

G and S are absorbing states: once there, a cell never leaves. F, A and R are transient.

Three matrices answer three questions

P = [ Q  R ; 0  I ]     N = (I − Q)−1     B = N R     t = N · 1

Q, transient to transient The 3 × 3 block among F, A and R.

N, fundamental matrix Expected number of visits to each transient state.

B = NR Probability of ending in each absorbing state, Good or Scrap.

t = N1 Expected number of steps before absorption.

Why N? A cell can visit A once, twice or more. N = I + Q + Q² + … adds up all those paths.

What we learned

An absorbing chain splits into Q and R. N = (I − Q)−1 counts visits, and B = NR gives the chance of ending good or scrapped.

CellCo’s line turns 93.3% of started cells into good cells, with 8 reworks per 100 cells.

Compare improvements on the same model and the same unit, yield per yuan. Combined changes interact, so test them together.
