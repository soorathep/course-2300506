Activity on node

Each box is an activity, each arrow a precedence. Boxes and arrows in amber lie on a critical path.

Forward and backward pass

Forward pass (earliest times): ES = largest EF of the predecessors, EF = ES + duration.

Backward pass (latest times): LF = smallest LS of the successors, LS = LF − duration.

Total slack = LS − ES. Activities with zero slack are critical: any delay delays the project.

Activity · Card network

Groups of 4 · 20 minutes · activity cards and a large sheet

Your group receives the eight activity cards in random order. Build the network on the sheet, then run the passes by hand.

  1. Place the cards so that every arrow points from a predecessor to its successor.
  2. Write ES and EF on each card (forward pass), then LS and LF (backward pass).
  3. How long does the project take? Which activities are critical? Which one can slip, and by how much?
  4. Gallery walk: check another group’s network and correct one error if you find it.

Studying alone: do the two passes on paper with the table on the project slide, then compare.

Activity · Answer

The project takes 19 weeks.

There are two critical paths, both 19 weeks long: A-B-C-F-H and A-B-E-G-H.

Only D, civil works, has slack: it can start up to 6 weeks late without delaying the project.

Two critical paths make the plan fragile: a delay on either the containers (C) or the power conversion system (E) delays commissioning. Shortening only one of them gains nothing.

Change a duration

Try shortening C from 8 to 6 weeks: the project is still 19 weeks, because A-B-E-G-H stays critical.

What we learned

An activity-on-node network shows precedence. The forward pass gives the earliest times, the backward pass the latest.

CellCo’s installation takes 19 weeks, with two critical paths. Only civil works has slack, 6 weeks.

With parallel critical paths, shortening one activity alone does not shorten the project.
